# AI 수익화 프로젝트 — 배포·자동 업데이트 안내

이 폴더는 **무료 정적 호스팅**(GitHub Pages 또는 Cloudflare Pages)에 그대로 올려 쓰는 묶음입니다.
서버·DB·계정 가입 비용은 0원입니다.

## 1. 폴더 구성
- `index.html` — 앱 본체. 데이터 기본값이 안에 들어 있어 이 파일만 열어도 동작합니다.
- `data.json` — 앱이 열릴 때 자동으로 읽는 최신 데이터. 이 파일만 고치면 다음 접속부터 반영됩니다.

## 2. 배포 (택 1)
### Cloudflare Pages
1. https://pages.cloudflare.com 에서 무료 계정 생성
2. "Upload assets" → 이 폴더를 업로드
3. 발급된 `https://<이름>.pages.dev` 주소를 폰 홈 화면에 추가

### GitHub Pages
1. 새 저장소(Public) 생성 → 이 폴더의 두 파일 업로드
2. Settings → Pages → Branch: `main` / root → Save
3. `https://<아이디>.github.io/<저장소>/` 접속

## 3. 자동 업데이트 방식
- 앱은 페이지를 열 때 `./data.json?t=...`를 읽어 **새 항목만 병합**합니다.
- 사용자가 앱에서 직접 고친 항목과 체크 상태는 `_u` 표시가 붙어 **덮어쓰지 않습니다.**
- 완전 자동(매일 09:00/16:30 피클 스캔 결과 자동 반영)을 원하면:
  1. 피클이 만든 결과를 `data.json`으로 저장
  2. GitHub Actions(무료)에서 그 파일을 저장소에 commit/push
  3. 다음 접속 때 앱이 자동으로 읽음
- 별도 서버·DB·유료 API는 필요 없습니다.

## 4. 데이터 보관
- 앱에서 입력한 내용은 그 브라우저의 `localStorage`에 자동 저장됩니다.
- 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로, 가끔 **설정 → JSON 내보내기**로 백업하세요.
- 엑셀 공유는 **설정 → CSV 전체 내보내기**(UTF-8 BOM)를 쓰면 한글이 깨지지 않습니다.
- 파일로 쓰다가 이 주소로 옮기면, 기존 데이터는 **설정 → JSON 내보내기** 후 새 주소에서 **JSON 불러오기**로 옮기세요(브라우저마다 저장소가 따로입니다).

## 5. 개인정보
- 자택 주소, 계좌번호, 전화번호, 주민번호는 `index.html`·`data.json` 어디에도 들어 있지 않습니다.
- 선택 기능인 4자리 PIN은 기기 안에 해시로만 저장됩니다.
